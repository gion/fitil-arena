# Machetele interfeței — skin-ul „Toy” (direcția A)

Aceleași ecrane ca în `reference/ui/` (direcția „Comic”), în varianta „Toy”: fundal indigo, panouri închise, butoane rotunjite cu „buză” 3D, galben pentru acțiunea principală. Un fișier `.dc.html` per ecran, la 844×390, exportate din canvasul de design pe 2026-10-07. Sunt referință de citit, nu cod de rulat.

În joc, skin-ul e implementat în `apps/client/src/ui/toy.css` și se alege din Settings › Look sau cu `?skin=toy` în URL. Detalii în `docs/design/ui.md`, secțiunea „Skin-uri”.

Canvasul live: https://claude.ai/artifact/5rH1dcy2uvaw4DJqTsSaKw (privat).
